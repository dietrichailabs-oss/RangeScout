# RangeScout 1.2 Streaming Review

Finnhub is the only production streaming transport. It uses the current user's credential, one provider-owned connection, bounded subscriptions, reconnect policy, candle aggregation, indicators, ticker updates, scanner observations, and alerts through the production runtime coordinator.

Yahoo operates in explicit snapshot mode. No provider failure is represented as a connected stream, and no deterministic fallback value enters the public runtime.
