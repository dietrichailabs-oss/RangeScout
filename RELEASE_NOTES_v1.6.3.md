# RangeScout 1.6.3 Engineering Candidate

RangeScout 1.6.3 is a narrowly scoped watchlist hotfix candidate.

- Selecting a watchlist now persists it as the current target without placing
  the list's entire membership into the single-symbol editor.
- Add Symbol and Remove Symbol operate on one validated canonical symbol and
  refresh the watchlist table, ticker ribbon, scanner filter, and runtime
  watchlist universe.
- The Active Symbol action clearly reports Add to Watchlist or Watchlisted,
  targets the selected list, and creates My Watchlist when no list exists.

This Engineering candidate preserves the published RangeScout 1.6.2 release
and remains pending Independent QA.
